拆解题目

先观察 f(x) 图像。改变 k，看看峰值和唯一正零点如何移动。
最终证明结论
x₁ < x₂ < 2x₁
特别注意：本题是 x₂ < 2x₁，通过比较 f(2x₁) 与 0 得到。
展开完整规范证明（含代数推导）
（1）证明唯一极值点与唯一正零点

由 f(x)=ln(1+x)−x+½x²−kx³ 得：

f′(x) = 1/(1+x) − 1 + x − 3kx² = x²[1−3k(1+x)]/(1+x)

令 x₁=1/(3k)−1，因 0<k<⅓，故 x₁>0。在 x>0 时，f′(x) 与 x₁−x 同号。于是 f 在 (0,x₁) 严格递增，在 (x₁,+∞) 严格递减，因此有且只有一个极值点 x₁，为极大值点。

又 f(0)=0，由严格递增性得 f(x₁)>0；且由于负的三次项占主导，lim₍ₓ→+∞₎ f(x)=−∞。结合连续性及 (x₁,+∞) 上严格递减，存在且仅存在一个 x₂∈(x₁,+∞)，满足 f(x₂)=0。注意 x=0 不属于题目所要求的 (0,+∞)。

（2-i）证明 g(t) 在 (0,x₁) 严格递减

设 g(t)=f(x₁+t)−f(x₁−t)。求导：

g′(t) = f′(x₁+t) + f′(x₁−t)
g′(t) = [6kt²(t²−x₁²−2x₁)] / [(1+x₁)²−t²]

由于 0<t<x₁，有 t²−x₁²−2x₁<0 且 (1+x₁)²−t²>0，再加上 6kt²>0，故 g′(t)<0，即 g 严格递减。

（2-ii）比较 2x₁ 与 x₂

由连续性，g(x₁)<g(0)=0，因此：

f(2x₁)−f(0) < f(x₁)−f(x₁) = 0

因为 f(0)=0，所以 f(2x₁)<0。同时 f(x₁)>0，而 f 在 (x₁,+∞) 严格递减，其唯一正零点为 x₂，故 x₁<x₂<2x₁。
