# 标准 HTML5 架构与动画硬约束（强制执行）

> 本文件属于 **阻断性规范**，不能用「已写 requestAnimationFrame」「页面看起来有动画」「代码没有语法错误」替代验证。

## A. 单文件 HTML 的标准结构

1. 必须是合法 HTML5 文档：`<!doctype html>`、`<html lang="zh-CN">`、`<meta charset="utf-8">`、`<meta name="viewport" ...>`、有意义的 `<title>`；层次明晰的 `<header>`、`<main>`、`<section>`、`<aside>`、`<nav>`/`<footer>` 等语义元素；`button` 真正操作按钮，`label for` 指向真实控件，`output`/`aria-live` 显示状态。
2. CSS 在内联 `<style>` 中，JS 在文档底部的内联 `<script>` 中，运行所需资产与数据全部自包含。禁用 `src`/`href` 指向的 CDN JS、在线字体和外部依赖；外链只能作为不影响功能的参考资料链接。**不要依赖现代浏览器允许 `file://` 访问旁边的另一个文件**。
3. 每个按钮有真实处理逻辑，允许键盘 Tab/Enter/Space 操作；响应式布局不裁切公式或主要图像。画布有清晰的标签/辅助说明，不能把所有信息仅画进不可访问的像素中。
4. 单一事实来源：题面、坐标参数、图形几何、公式数值由同一数学模型派生。禁止展示层重新手写一套不同坐标或近似式。显示数值须注明近似与精确的区别。
5. 每个教学章节必须覆盖题面、基础知识、方法选择原因、完整步骤和总结；自动演示是这些内容的可视化控制器，不是章节幻灯片自动轮播。

## B. 强制状态模型：一个全局时间，一个状态函数

唯一全局播放时间 `playheadSec`，严格在 `[0, durationSec]`。其他函数不可拥有会独立向前走的「隐藏教学时钟」。

- 教学章节统一采用**全局秒数**：每条事件明确 `startSec`、`endSec`，不可在同一数组把绝对时间当成相对时间比较；若章节内容确实用相对时间，必须在 `sceneAt(globalSec)` 中先转为 `localSec=globalSec-chapter.startSec`，面板与动画统一只取 `localSec`。禁止跨坐标系比较。
- **`sceneAt(globalSec, params)` 必须是纯函数**：不读取真实当前时间，不推进物体、不写 DOM、不保存内隐状态；返回所有显示所需数据：场景内线/面/点/透明度/镜头/标签、当前公式和解释、进度。该函数对同一个时间和参数调用任意次数必须返回同样结果。
- 唯一更新入口 `applyTime(t)`：在一次事务中执行 `const state=sceneAt(t,params); renderScene(state); renderText(state); renderControls(state)`。播放、暂停、进度条跳转、上一步、下一步、参数变化都调用同一入口。禁止在三个事件监听里写三套独立 DOM 更新/渲染逻辑。
- 用 `requestAnimationFrame` 结合时间戳计算增量。播放暂停要清理时间戳；页面隐藏自动暂停；帧驱动只在播放或视角拖动等状态变化时重绘，不允许每帧插入大量 DOM 节点。
- `seek(任意时间)` 必须立刻恢复 **完整状态**，包括过渡中间态；不能依赖此前从头播放到这里的历史过程。`seek(0)` 必须看到初始帧，`seek(duration)` 必须看到结论帧。返回再跳同一时间结果应一致。
- 自动播放时进度条 value 每帧（或不低于可感知变化的频率）刷新，`aria-valuenow`/文字时间与同一播放头同步；点击暂停后二者都不再向前。0.5×/1×/2×实际改变动画速度而非仅改变标签。

## C. 动画是真正随时间改变的数学对象

- **线段生长**：必须画到插值终点 `A + p(B-A)`，或逐渐追加坐标序列点；仅计算 p 却仍然绘制完整 `A→B` 是重大缺陷。
- **函数生长**：先坐标系；随着 `visibleX` 增大，只有 `x <= visibleX` 的曲线被画出。切线、运动点、导数符号和对应公式须随 `visibleX` 变化；端点、奇点、定义域正确。
- **空间几何**：刚体变换保持长度和角度不变量，面与线有明确前后遮挡、深度排序/深度测试、透明策略；3D 模型、弧线、平面必须源自真实三维坐标，不能靠绘制误导空间位置。复杂情形优先使用离线内嵌的 WebGL 渲染器（可自写原生 WebGL），不强制下载外部库；如用 Canvas 透视，必须明确实现深度与遮挡处理，不可直接以 2D 线框冒充准确 3D。
- **镜头运动**：平滑插值控制 yaw/pitch/distance，鼠标接管后暂停自动镜头，复位能恢复标准视角。保证学生关注对象不会被面遮挡或跑出边界。
- **教学解释**：每一个关键画面变化有对应数学说明；文字不允许在多个关键步骤里保持为上一步讲解。公式可以分行渐显，但完整严谨解答须可独立查看。

## D. 性能与清晰度

- Canvas 用 CSS 布局宽高 + DPR 缩放：`canvas.width=round(cssWidth*dpr); canvas.height=round(cssHeight*dpr); ctx.setTransform(dpr,0,0,dpr,0,0)`；2D 绘图统一使用 CSS 像素，避免宽高混算。窗口调整需刷新。
- 停止播放时停止无意义重绘；动画帧尽量只绘制 canvas，不在每帧重写大段 innerHTML。字体与图像的加载不能依赖网络。
- 进度跳转和缩放后点名可读，标签尽量不互相遮挡；当画面拥挤时优先逐层呈现重点元素，允许隐藏暂不相关的对象。
- 播放速度稳定：推荐用秒数驱动参数插值；不使用 `setInterval` 充当主要动画时钟，不把 CSS transition 的结束时间当成数学状态。

## E. 强制可测试接口（所有正式成品）

在 HTML 中暴露仅供校验的只读快照接口（可直接复制例子里的写法）：

```js
window.__lessonQA = {
  getSnapshot: () => ({
    timeSec: playheadSec, durationSec, playing,
    chapterId: state.chapterId, captionId: state.captionId,
    // 不是渲染调用次数，而是反映数学图形/镜头的确定性状态
    sceneSignature: state.sceneSignature,
    visualProgress: state.visualProgress,
    playbackRate: speed,
  }),
  seek: (t) => seek(t),
  play: () => play(),
  pause: () => pause(),
};
```

字段应反映真实内部状态；禁止假造返回值蒙混测试。`sceneSignature` 可用一组数值归一化字符串（如模型的角度、坐标、透明度、镜头、扫描位置），务必在视觉变化时变化、同一个时间再次定位时完全可复现；`captionId` 在教学子步骤转换时变化。提供 `data-lesson-control="play|seek|speed"` 标记给浏览器自动化定位（示例已提供）。

## F. 强制阻断门槛（任何一项不通过即不合格）

1. 用 `scripts/validate_delivery.py` 对文件做静态预检；错误必须清零。
2. 用 `scripts/browser_contract_test.py` 实际启动 Chromium，至少检查：初始态、真实进度递增、进度条跟随、暂停停住、从中段继续、随机 seek 可重复、两个章节及其内部文案变化、两种屏幕尺寸、浏览器控制台异常、页面可见状态。建议 `python scripts/browser_contract_test.py 交付文件.html`。
3. 演示类任务必须人工检查至少 0%、25%、50%、75%、100% 五帧的数学图像，记录结果；函数需再检查一个极值附近，几何需再检查关键角/变换端点。
4. 公式和结论须用独立计算方式核验。图像直观、数值实验、严格证明不能混淆。
5. **未实际运行浏览器，不得宣称“已测试”“流畅无卡顿”“完整验收通过”**。如果环境限制，必须明确标注未通过项，交付也不得标为「已验收完整成品」。

最后验证原则：是否「标准 HTML」与是否「合格数学微课堂」是两个维度；合法 DOM 不能替代正确时间线，动画正确也不能替代完整证明。两个维度都必须通过。
