# V3 教学分镜模板：让画面真的教会学生

## A. 生成任何 HTML 之前先输出内部教学表（可写注释，不要求用户另外上传文件）

| 字段 | 目的 | 合格判据 |
|---|---|---|
| stepId / tab / 时间范围 | 课程中的唯一身份 | 可从任意时间重建相同画面 |
| 目标 objective | 本步要解决的明确小问题 | 学生读完能说“正在求/证什么” |
| 学生已有条件 evidence | 本步依赖什么 | 字符/图形都准确 |
| 为什么 why | 为什么采用此知识或构造 | 能建立从目标到方法的因果，禁止只有“令...” |
| 新概念 miniLesson | 需要从零讲哪个知识点 | 有定义、必要条件、例子、误区、实际用途 |
| 画面 action | 随时间变化的**数学对象** | 有初态/中态/末态截图（而非淡入） |
| 推导 derivation | 当前必要的完整计算 | 关键等式/定理有理由，可独立核验 |
| 结论 takeaway | 当前得到什么 | 与下一步能连接 |
| 提问 question | 学生此刻应想什么 | 反馈解释数学原因，不只是正确/错误 |
| 画面取景 camera | 看哪里更有利于理解 | 关注对象在舞台可见，标签不重叠 |

### 分镜必须小于数学认知负担

不是“一个知识点一幕”，而是**一个可理解的数学变化对应一个微步骤**。没有固定幕数和播放总时长；先按严谨推导拆完，再确定时间。每个细分步骤可安排观察阶段与结论阶段。必要时自动演示有短暂停顿，但不能让界面死静似卡住。

### 典型时序（每一小段按题目调整）

- 0–20%：聚焦当前目标与学生容易忽略的条件；模型布局和辅助线逐步出现。
- 20–45%：展示新知识的**单独动态图示**，并让学生预测。
- 45–70%：在本题图上验证知识适用条件，逐条建立推导。
- 70–90%：逐行出现严谨公式、推理与当前结论，图形持续标注对应对象。
- 90–100%：总结小结论，提出下一步需要解决的问题。

这只是一段知识讲解的节奏范式，**不是全题百分比模板**。

## B. 具体对照 1：线面垂直判定

**不合格画面**：右侧两行写“AE⊥CE，AE⊥DE ⇒ AE⊥平面BCD”，舞台只高亮 AE/CE/DE，接着跳到下一页；学生没见过“平面内两条相交直线”，仍不懂为什么。

**合格 4 次推进**：

1. `提问`：AE 与 CE、DE 分别垂直，能得到 AE 和整个平面的关系吗？图中只高亮 E 点附近两条关系。不要立即公布结论。
2. `知识动画`：用一个简化平面 α、两条在 O 相交的直线 m/n，以及可转动的直线 l；强调“交于 O”这一必要条件。真正展示 l 的空间方向与整面关系。文字解释定理，不在此处偷换成“任意两条线”。
3. `回到本题`：透明平面 BCD 渐显，CE 与 DE 相交于 E 的直角记号逐一出现；右卡逐项核对定理前提。
4. `严谨得证`：再显示 `AE⊥平面BCD`；问学生“为什么不能只用 AE⊥CE？”给反馈。接下一小目标。

## C. 具体对照 2：函数导数与单调性

**不合格画面**：一次性给完整 f 图、写“f'＞0 所以单调增”。

**合格 5 次推进**：

1. 坐标系和定义域先出现；函数曲线逐 x 生长，运动点实时 `(x,f(x))`。
2. 点走过上升区间，切线随点转动，斜率 `f'(x)` 显示正号；学生预测会不会一直上升。
3. 接近极值，慢速展示切线趋于水平；明确 `f'(x)=0` 是候选临界点，**不能只凭 f'=0 断言极大值**。
4. 继续到下降区间，导数为负；两侧导数符号改变与极值判断形成对应。
5. 把本题解析里的符号表逐步生成，解释为什么研究导数、怎样确定参数范围及唯一性；最终证明是由导数符号和数学性质得出的，不是“图像看起来如此”。

## D. 具体对照 3：法向量求线面角

**不合格画面**：同时出现两箭头、三行点积、最后 `sin θ=...`，完整过程藏在折叠栏。

**合格**：

- 先让学生看到“直线与平面的角”的定义：垂足沿法线运动并形成射影线，角弧逐渐生成。
- 再提出直接投影的困难，说明为什么改用法向量。
- 建系前逐条展示三条轴为什么互相垂直，坐标由哪条长度条件得到。
- 展示平面内两条不共线的向量，法向量从其点积方程组求出并画在场景中。
- 推导 `sin θ=|v·n|/(|v||n|)` 的来源，强调与法向量夹角互余，并分行计算。
- 最后给精确答案与检查思路；动画保留法向量、线段和角弧作为证据，不一键清空。

## E. 右侧教学卡分层排版

建议一个活跃步骤有：

```text
第 07/15 步 · 知识理解                 进度 07/15
────────────────────────────────────────
当前要解决：怎样从两条垂直推出线面垂直？

思考：单靠一条垂线，还不能保证直线垂直整个平面。

[深色/浅色卡片：当前图形观察和已知条件]
[公式块：判定条件 ① ② ③ → 得出结论，分行显示]

[本步结论：AE ⟂ 平面 BCD]    （正确时才突出）

[学生思考：如果 CE 与 DE 平行，原结论还能推出吗？]
  [提示] [揭晓并解释]
────────────────────────────────────────
下一步：用它怎样证明 CD ⟂ AB？
```

不是每个位置始终摆满文字；动画前半段可以仅显示目标/预测，后半段逐渐加上依据、推导、结论。**跳转到该步骤的末态应显示完整内容**。

## F. 交付前必须认真走一遍完整学习路径

- 第一次从头播放，假设学生刚学完基础知识；问自己“这段动画是否真的解释了刚刚出现的数学式子？”
- 点击任意知识章节，学生应该看到一个可理解的**教学示例或动画**，而不只是概念名称。
- 在每一问最后，右侧必须存在完整证明的关键推导链；下方折叠的完整答案只作辅助。
- 打开思考题，错误选项反馈不能只有“答错了”，应指出丢了哪个数学条件。
- 手机宽度 390px 下，图形、导航、教学卡、播放器均可操作，公式不应横向溢出。
