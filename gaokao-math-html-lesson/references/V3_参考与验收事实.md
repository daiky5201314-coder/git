## 测试限制

Chromium 在当前容器中对 `file://` 导航受到环境级阻断，因此使用**完全相同的 HTML 字节内容**进行浏览器渲染和行为测试；未验证用户电脑操作系统直接双击该 HTML 的实际结果。页面本身无在线依赖。

以上结论只针对 **包内 V3 联合示例**，不意味着新 Agent 未来生成的所有试题都自动合格。每道新题都需要独立核题、数学审核、浏览器测试、截图审片与人工教学效果判断。
