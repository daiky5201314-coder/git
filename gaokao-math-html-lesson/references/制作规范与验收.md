# 制作规范与严格验收（V1.0 + 连续动画修订）

## 1. 教学任务定位

- 每道高中数学试题都必须是一节独立、完整、可操作、可观看、可理解、可自学的数学微课堂。
- 用户仅需上传题目文字/截图/PDF，或提供明确年卷题号；制作者承担检索、核题、解题、分镜、编写、测试全部工作。
- 学生可以从弱基础开始学，理解为什么这样解题；不能仅堆公式，也不能只靠漂亮的动态画面。

## 2. 五个内容模块

### 模块 A：原题与题意

必须逐字准确展现全部题设、公式与图（必要时画等价准确图），并逐项解释条件的实际含义、未知对象、求解目标、容易看漏的约束；定义域/参数/图形位置不可遗漏。

### 模块 B：基础知识

对解题必需的每个关键知识点说明：**定义 → 适用条件 → 公式/定理 → 直观图或动态例子 → 在本题中的用途 → 常见误区**。例如“导数 >0 说明函数递增”需要配合变化中的切线斜率和正确的区间条件；“二面角”要展示如何在棱上取垂线构成平面角。

### 模块 C：如何想到解法

解释：题目条件触发什么联想？为何选导数/构造/辅助面/空间向量？关键中间量有什么作用？选择当前方法之前可简单解释为什么直接算不方便。构造辅助函数前，必须指出希望比较什么、为什么作差能化简。

### 模块 D：完整、严谨的标准解答

按“当前目标 → 思考理由 → 数学操作 → 动画呈现 → 结论”拆小步。关键等式必须有依据，不跳决定性计算，不把必要条件当充分条件。包含定义域、端点、参数区间、不同情形；最后证明应可脱离动画单独成立。

### 模块 E：总结巩固

包括两问/多问结论、核心思路一览、重要公式、错误示例、一至两题思考/选择题（有正确答案和具体反馈）。

## 3. 题型动画质量

### 函数类（涉及图像时）

1. **第一帧是坐标系**，函数曲线按定义域随扫描 x 坐标逐点绘制；运动点数值和图形同步。
2. 画出从上升→转折→下降的过程，关键极值/零点按到达时间强调或短暂停顿。不是一次展示全曲线再平移遮罩。
3. 切线逐点更新方向，显示当前 `f′(x)` 及正、负、零状态；有意义时导函数图像联动。
4. 参数滑块只可进入题设允许范围，拖动后曲线、极值、零点、辅助函数及结论同步重算。
5. 比较类题画差值/交点/对称点/辅助函数，并用动画说明它们与证明目标的关系；**图像观察不能代替证明**。

### 空间几何类

1. 真实三维坐标模型，点、边、面数学上符合题设；允许鼠标/触控旋转、缩放、重置视角。
2. 翻折必须以正确折痕为旋转轴，长度和夹角不变；底面与翻折面可用半透明区别。
3. 线面平行/垂直需显式画辅助平面或辅助线，并解释定理前提。
4. 二面角可展示平面角或两个法向量夹角，需严格区分“实际刚体旋转度数”和“二面角的内部度数”。
5. 坐标/向量动画须与证明所选坐标系完全一致，不任意改轴向。

### 其他数学题

数列按项生成，三角函数单位圆与图联动，解析几何画真实轨迹，概率可重复随机试验并解释随机误差。不强制使用 3D。

## 4. 真实自动演示验收

- **点击 ▶ 自动演示**，无需再点按钮就能完整看到数学曲线/几何对象真实连续运动，直到全题结束。
- 当前动画阶段的标题、推导式、解释与图形动作同步；学生能明确看出此刻正在说明什么。
- 暂停精确停在当前时刻，继续不跳帧、不重头；进度条可随机定位 10%、50%、90%；上/下一步定位到教学幕起点；重播从 0 开始；变速不改变数学结果。
- 当学生手动操纵视角或参数时，自动动画暂停或安全转换至探索状态，避免与时间线争抢。
- 不依赖 `setInterval` 每隔数秒轮播页面冒充动画；避免每帧重建大量 DOM、持续创建巨幅画布或不断运行重计算。

## 5. 展示与交互

电脑端主要动态视图 + 右侧思路和公式 + 底部控制；手机纵向，自适应画布像素比和控件尺寸。界面简洁，符号准确、可读性好；颜色具备稳定语义（主对象蓝/辅助紫/当前橙/结论绿/不满足条件灰红），并通过形状/标签区分，而非只依赖颜色。

功能覆盖：播放/暂停/继续、上一/下一、重播、重置、进度、速度；按题型提供函数参数、坐标读数、图形缩放、显示切线/法向量/辅助面、定角定位和互动思考题。所有手动操作后数据必须一致。

## 6. 技术形式

- 最终为**一个完整 `.html` 文件**；内联 JS/CSS 和必要资源，单独保存后双击运行。
- **断网环境仍完整可用**：禁止远端脚本/模块、Web 字体、远端图标/图片、必须联网的数学排版；必要库可内嵌为单文件，但需遵守授权和体积合理性。
- 优先原生 Canvas/SVG。复杂 3D 可用直接投影/原生 WebGL/将适当的 3D 库代码打包内联。`file://` 不应触发模块 CORS 问题。
- 控制总画面绘制负担，隐藏标签页时停止或暂停演示；设备像素比设上限；降低过度阴影与无意义效果。

## 7. 最终逐项勾验

- [ ] 原题来源和每个条件逐一核对
- [ ] 自己独立算出答案，符号/数值/端点/特殊参数验证
- [ ] 每个关键知识点都在当前 HTML 中有基础解释
- [ ] 讲清解法从哪里来以及每步为什么做
- [ ] 证明严格、完整，不能拿动画作证明
- [ ] 题目要动的数学对象实际在动，而不只是章节切换
- [ ] 动画/文字/公式/参数/标签动态一致
- [ ] 实现真正连续的自动演示与暂停/继续/变速/拖动
- [ ] 函数按定义域生长、导数按斜率联动（对应题型）
- [ ] 几何旋转保距，面/角度/法向量准确（对应题型）
- [ ] 有基础知识、思路、完整推导、总结、自测
- [ ] HTML 离线完整，Chrome/Edge 可以双击打开
- [ ] 控制台无异常，电脑/手机均实测
- [ ] 明确交付真实文件和已测/未测范围

有一项关键门槛不满足，不得标记为“完整教学版”；不能因时间紧用静态 PPT 式答案替代数学运动。
