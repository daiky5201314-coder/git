# 已确定的设计取舍

本文件替代对原对话的依赖。后续 Agent 不需要知道之前谁说过什么，只按决策执行。

1. **不是建课程平台，也不是设计网站系统。** 成品永远是一题一个独立的 `.html` 文件，学生双击即可学习。
2. **每题从头完整制作。** 不依赖其他题目文件、外部知识点文件、在线 API、CDN、历史会话；这一题用到的概念和动画、完整证明都包含本题 HTML 内。技术实现可采用合适算法，但交付不得需要额外文件。
3. **教学深度高于 Demo。** 早期 2025 年第 17 题做过简单 3D Demo；第 18 题做过函数操作 Demo。正式作品必须补齐前置知识、解题逻辑、逐步推导、易错点与学生练习。
4. **连续自动演示不是自动翻页。** 曾出现“固定停留 8.6 秒然后切换一页”使学生觉得卡顿的问题。必须使用连续时间线，数学元素真实运动/生长，文字公式按时间线出现；画面停留时要有明确观察意图而非程序无响应。
5. **动画优先讲清数学。** 函数由坐标系起笔、曲线逐步生长、切线随点运动、关键点强调、变化趋势明显；几何有真实刚体翻折、可旋转和缩放的 3D 模型、透明面和有意义的辅助线。
6. **无需用户先准备参考视频。** 如果需要学习动画表达方式，制作者可以自行查找优秀案例，仅借鉴动画语言，不能拷贝别人的作品。
7. **交互教学 + 完整标准证明并重。** 可视观察不能代替严格证明。每一步应解释“为什么想到这一做法”，而不仅展示结果。
8. **无外网也可看完整内容。** 浏览器打开离线运行；课件核心依赖文件内自包含代码和资源。
9. **交付前实测。** 数学、JS、滑块、播放/暂停/继续/回放/时间定位、手机/桌面、断网均应检查；不允许声称测试过实际没做的环节。
