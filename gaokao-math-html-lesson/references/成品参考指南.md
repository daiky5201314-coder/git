# 参考成品怎么读，避免学错重点

## 1. 完整成品：第 17 题

文件：`examples/旧版教学视觉参考（非V2技术模板）/2025新高考II卷_第17题_完整成品.html`

双击在 Chrome/Edge 打开，观察整个数学课件。先点“自动演示”，看它是否从原图构建，到沿 EF 真实翻折，到辅助面的浮现、线面平行、空间坐标、法向量、二面角计算，最后过渡到总结与练习。然后拖动进度条、暂停、恢复、手动调角度/视角，并打开完整标准解答。

**可以借鉴的方面**：课程布局、章节与主动画的关系、同一个数学模型贯穿多幕、从全局时刻计算动画状态、场景中的透明面与方向箭头、知识问答、暂停时避免重绘。

**必须重新设计的方面**：新题的全部知识点、解题逻辑、坐标与函数模型、动画语义、关键点、提示题、标准证明；不能简单替换题目标题却沿用第 17 题数据。

**注意**：成品是一种可接受的高质量参考，不是要求照抄其 14 幕数、1 分 48 秒时长或字体/配色。

## 2. 函数生长 + 切线技术样例

文件：`examples/旧版教学视觉参考（非V2技术模板）/函数生长_切线_完整离线示例.html`

功能点：坐标轴先出现、函数曲线依 x 范围逐步生长、跟随的运动点、由导数决定的动态切线、导数符号与升降提示、可调参数、暂停/继续/重播/进度条、单 HTML 离线运行。

这只是**动画技术参考**，不是为某道高考真题写成的完整教学课件。真正的函数高考题必须额外加入原题、该题需要的全部前置知识、方法选择原因、完整严谨的推导、易错点、自测，以及函数图与解题步骤严格同步。

## 3. 第 18 题旧 Demo（对比用）

文件：`examples/旧版教学视觉参考（非V2技术模板）/2025新高考II卷_第18题_旧版交互技术参考.html`

展示如何在 Canvas 中实现一个参数化的数学函数、零点和对称差函数的图形，以及规范数学证明文本。但它是初期验证性质的交互样例，**不代表完整教学质量**。以其静态或弱同步播放方式充当连续自动演示会不合格。

## 4. 验收与改进

完成任何新题时先看参考做到了什么，再读 `references/制作规范与验收.md`、`references/动画导演与实现.md` 确认是否满足函数生长/3D 翻折/完整证明/真实自动演示等本题适用项。浏览器跑通之后再交付。
