# V2.0 Skill 内置技术示例验收记录

测试日期：2026-10-21。

## 工程检查

- 样本：`examples/标准HTML5_时间线和状态同步技术示例.html`。
- `scripts/validate_delivery.py`：**通过**，HTML5 结构、内联依赖、状态管线、可测试 API 均存在。
- `scripts/browser_contract_test.py`：**通过**（Chromium 桌面 1440×900 与手机 390×844，网络禁用）。详见 `tests/browser_test_log.txt`。
- 核对项目：初始状态、5 个 seek 关键帧、画布真实像素变化、重复 seek 相同场景签名、章节内部文案变化、自动播放时间递增、进度条同步、暂停/继续、JavaScript 异常、移动端横向溢出。
- 数学技术示例 `f(x)=x³/3−1.5x` 的导数为 `f′(x)=x²−1.5`，驻点 `x=±√1.5`。这不是对特定高考真题的原题审校。
- Chromium 当前宿主阻止 `file://` 导航；测试通过**同一 HTML 文件的原文内容**加载到 Chromium 进行。页面不含外部运行依赖，并在网络禁用时通过；但**未完成操作系统双击打开行为验证**。

## 失败对比样本

上传的 `2026云南高考数学16题_三棱锥线面垂直与线面角_可视化微课堂.html` 用 V2 静态预检：**失败**。缺少语义 `<main>`、正式测试接口、统一 `sceneAt/applyTime` 管线和交互测试标记。更重要的实际问题另见 `references/失败案例与修复检查表.md`。

## 限制

目前自动化可验证实际时间/进度/字幕变化/Canvas 像素变化，但不能自动证明每道未来数学题的严谨性、3D 遮挡的真实性或复杂几何动画的教学效果。未来作品必须在交付前独立完成数学审校和视觉人工检查，不能引用本包的通过记录代替对新文件测试。
