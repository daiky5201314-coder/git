# 动画导演 + 连续播放 + 性能要求

## 总设计原则

**可观察的数学变化**始终是主角。镜头过渡、柔和淡入、文字出现只是讲解工具。图像、公式、讲解必须按同一时间/数学状态同步，而非三个独立定时器乱跑。

## A. 自动演示的实现范式

推荐用**全局时间轴 + 关键帧/阶段纯计算**：

```js
const duration = 96; // 每道题根据讲解需要确定，不固定每步停几秒
let playhead = 0, playing = false, rate = 1, last = null;
function sceneAt(t) {
  // 纯函数：根据全局秒数求当前动画的完整状态
  // {chapter, foldAngle, camera, visibleGeometry, curveProgress, caption, formula}
}
function loop(ts) {
  if (playing) {
    if (last !== null) playhead = Math.min(duration, playhead + Math.min(.07,(ts-last)/1000)*rate);
    last = ts;
  } else last = null;
  const state = sceneAt(playhead);
  if (playing || dirty) { render(state); syncText(state); dirty=false; }
  if (playhead>=duration) playing=false;
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);
```

- `sceneAt(t)` 必须能定位任意时刻；按需用 `smoothstep` 缓动。不要用 `current += (target-current)*.08` 这种依赖帧数的方式当唯一驱动，否则慢机器拖尾或无法精确 seek。
- **拖进度条**、上/下一幕、暂停/继续、速度变化都改同一个 `playhead`。当前幕、公式、字幕由 `sceneAt(t)` 生成/同步；换幕才更新需要变化的 DOM，避免每一帧重复改 `innerHTML`。
- 暂停时也停止高成本绘制；允许直接 `requestAnimationFrame` 循环但仅在 `dirty` 或播放时绘图。优先事件触发绘制或可见性暂停。
- `visibilitychange` 暂停离开标签页的动画，不要悄悄跳过概念；如果时间源在后台运行，恢复时需重置 `last`。
- 手动操作参数/视角时暂停演示，保留当前形态供自由探索；重新开始演示可平滑过渡。

### 体验上的“卡顿”三类

1. **内容卡顿**：某幕数秒无数学变化，像播放器挂了；通过有意义的渐进画线、构造、镜头/视角、观察任务处理（必要停顿应显示倒数/提示）。
2. **渲染卡顿**：Canvas 不必要地重复绘图、每帧更新大段 DOM、DPR 过高、作图点数过大；通过状态缓存、离屏背景、DPR 上限、视口裁剪、轻量标注和避免垃圾对象降低负担。
3. **切换卡顿**：拖动或点击下一步时物体瞬移或文字滞后；应以时间轴为真值，按暂停/seek/过渡规则精确复位。

“无卡顿”不可仅凭代码结构断言，必须浏览器实测。

## B. 函数图像真正生长（必须掌握）

1. 根据定义域确定绘图区间 `[xmin,xmax]`，含对数/分式等时切断非法点与渐近线；非有限值不得连线。
2. **先画坐标轴与刻度**。对于 `progress∈[0,1]`，仅绘制 `xmin ≤ x ≤ xmin+(xmax-xmin)*progress` 的曲线，不能提前展示完整最终图。
3. 将末端动点绑定到当前 x，显示 `(x,f(x))`，导数 `f′(x)`；到达极值/零点时强调与适当放慢，使学生观察符号变化。
4. 允许绘图单独进度拖动；暂停不丢当前扫描位置；重播可以从 0 再逐步生长。画面标注的固定数学极值/零点由数学计算，不能依赖用户刚好拖到的位置才存在。
5. 需要导数讲解时显示 `y=f(x0)+f′(x0)(x−x0)` 当前切线，伴随扫描 x0 移动，`f′>0/0/<0` 与升/平/降联动。**在端点附近切线可超出画布，应裁切而非跳线**。
6. 参数变化会影响曲线/根/极值/坐标区间，至少更新已显示的所有数学数据，避免使用旧数据标注新曲线。

**可运行参考**：`examples/旧版教学视觉参考（非V2技术模板）/函数生长_切线_完整离线示例.html`，内含绘图、自动演示、暂停、参数、切线、转折点动态标签。

## C. 空间翻折（以第 17 题为参考）

- 选轴 `EF`，以同一旋转矩阵变换 A、D 得到 A′、D′。沿轴 EF 的点保持不动，距离/平行/垂直等原本保持的性质必须复检。
- 对 2025 新高考 II 卷第 17 题，一种合法坐标（设 AD=1）：`E=(0,0,0), F=(1,0,0), B=(0,2,0), C=(1,1,0)`，翻折前 `A=(0,-1,0), D=(1,-1,0)`；目标 `A′=(0,1/2,√3/2), D′=(1,1/2,√3/2)`。
- 题设所成**内部**二面角 60°，而从原来水平向下的半平面绕 EF 刚体旋转到目标是 120°。角标应显示两者含义，不能混为一谈。
- 几何计算层面的严格证明单独写在 `references/数学审校.md`。图形帮助发现平行/方向关系，但不能代替证明。
- Canvas 3D 投影与真实 WebGL 3D 均可，只要空间坐标真实、可旋转、可缩放、透视正确并满足数学约束；无需强制远程 Three.js。

## D. 解题步骤与动画同时推进

一幕的字段应至少包含 `title / aim / basis / visualFrom / visualTo / formula / explanation / conclusion / holdOrQuiz`。每帧更新数学可视对象与进度；在公式正式给出结论前，可以先给学生预测（例如“切线斜率在极值附近发生什么变化？”）。

- 不要在画面还未开始构造辅助面前就声称“辅助面已经平行”。
- 不要先放最终答案再让图形补动作；先观察→解释→严格公式→结论。
- 空间法向量出现时，对应法向量的点积条件公式应同时出现；函数极值出现时，应说明导数符号如何跨越 0。

## E. 可用性与离线

- `canvas.width = cssWidth * Math.min(devicePixelRatio,1.5或2)`，并设置 context transform。
- 交互区域 `pointerdown/move/up`，触控手势如 `touch-action:none`，缩放 wheel 的事件注册 `{passive:false}`。
- `file://` 可以直接打开，不使用 `import` 从本地文件读取、在线字体、远程脚本和联网图片。
- 在普通桌面和手机至少两种尺寸测试；关闭网络测试。
- 在数学动画上区分可视观察与正式证明，在画面或解释上标注“直观展示”/“严格证明”。
