# 高中数学单题 HTML 可视化微课堂制作 Skill V3.0 · 视觉交互与工程双重强验收版

## 唯一目标与交付

**收到任意一道高中数学题后，将它当作第一次遇到的全新项目**。制作一节让学生能够“理解题意 → 预备知识 → 想到解法 → 看到动画解释 → 严格推导 → 独立巩固”的微课堂。

最终必须交付 **一个自包含 `.html` 文件**，桌面或手机 Chrome/Edge 双击打开；不需要服务器、不需要安装软件、不得依赖外部 CDN、字体或远程脚本。可附自测记录，但核心教学必须都在交付的 HTML 内。**不是提供教程、设计建议、代码片段或几页静态答案来代替成品。**

**核心分界线：自动演示（连续的数学对象运动、线/面的绘制和推导同步）≠ 自动讲解（只自动切换文字或章节）**。点播放后学生必须看到真实、连续、可暂停和定位的数学动画。静态变化/淡入只能辅助，不能充当核心数学演示。

## 每次启动时必须读取的材料

**第一优先级（必须先读、先打开参考成品）：** `references/V3_视觉与交互设计硬契约.md`、`references/V3_教学分镜模板与具体对照.md`、`references/V3_视觉验收与反例报告.md`；以及 `examples/首选视觉交互参考_2025第17题.html`。**这套成品的界面、互动和教学组织方式是主要产品基准。**

**第三个必看的联合样例：** `examples/V3_联合视觉与工程示范_函数入门非真题.html`。它同时满足 V2 动画状态合同与 V3 教学交互/版式合同，演示函数生长、导数知识、逐步推导、同步控制和思考反馈；**不是高考真题完整教学成品，不得当作新题答案复制**。新 Agent 应先看真正高考第17题的整体教学效果，再学习该样例怎样用标准 HTML5 架构做出相近的交互体验。

**第二优先级（不可省略）：** `references/标准HTML架构与动画硬约束.md`、`references/失败案例与修复检查表.md`。V2 解决技术逻辑，V3 解决学生看到的最终画面与学习体验。两者必须同时满足。


- `references/制作规范与验收.md`：完整教学模块、题型特性、独立 HTML 规则。
- `references/全流程SOP.md`：收到文本、图片或 PDF 后怎样检索、核验、建模、制作、实测、交付。
- `references/动画导演与实现.md`：函数生长、空间翻折、切线/法向量、时间线、低卡顿。
- `references/数学审校.md`：符号、证明、参数、极限、角度等数学核验方式。
- `references/成品参考指南.md`：如何正确借鉴本包自带的实际成品。

没有其他题目代码时仍要完成整道题；无须用户额外准备视频、图片、项目、SDK 或技术环境。

## 不可跳过的制作流程

1. **锁定原题。** 优先逐字核对用户上传的图片/PDF。若仅有“年份+卷名+题号”，主动查找可靠原卷并交叉确认；年份、地区与使用的卷型先校对。图形、条件、定义域、题号、分值逐项检查。版本不一致时标明来源与采用版本，不能根据记忆编造。
2. **独立完整求解。** 在开始可视化前手动推导，必要时用 Python/SymPy 数值或符号校验；查参考答案但不盲信。检验参数范围、端点、特例、反向命题、几何不变量。明确动画哪些现象只是直观，哪些结论有证明。
3. **从基础构建教学内容。** 不预设学生了解导数、切线、二面角等知识；本题用到的重要知识均在当前 HTML 中完整解释定义、公式成立条件、直觉、例子、常见误区和本题用途。不能把学习内容留给其他网页。
4. **写出解题“为什么”。** 每问组织“目标→观察→方法选择原因→关键突破口→推导→结论”。特别解释**为什么构造辅助函数/平面/向量**，而不仅是“令……”。完成全部标准证明，不许因有动画而省略数学步骤。
5. **先做知识点教学和动画分镜。** 为每幕定义数学目标、所需画面、变化起止、公式何时出现、学生提问/停顿、结论触发，组织一条可自动播放的总时间线。复杂内容可以细拆；动画必须贴合数学因果。
6. **采用 V2 强制工程骨架。** 参照 `examples/标准HTML5_时间线和状态同步技术示例.html`；HTML5 语义结构、一个全局播放头、`sceneAt(t,params)` 纯函数、`applyTime(t)` 统一入口、真实中间态、`window.__lessonQA` 测试接口、三类数据控件测试标记缺一不可。**不是仅创建 requestAnimationFrame 就算实现自动演示。**
7. **制作独立 HTML。** 内含 CSS、JS、题面、知识点、交互、完整证明。按题型选择 SVG/Canvas/原生 WebGL；3D 拖动、平面透明和角度必须真实。离线可用为硬约束。
8. **提供真实自动演示。** 播放时图形随时间连续运动；暂停停在当前位置；继续平滑衔接；可拖进度条、上一步/下一步、重播、调速度。手动拖动和自动播放不矛盾，且所有标签、公式、坐标与图像一致。
9. **双重阻断性验收。** 对新文件必须运行 `python scripts/validate_delivery.py <html>`、`python scripts/browser_contract_test.py <html>` 和 `python scripts/visual_teaching_contract_test.py <html> --shots ./视觉验收截图`；任一硬性失败就先修复再交付。再人工对照 `assets/首选视觉基准_第17题_证明步骤.png`，检查教学卡、知识点动画、公式推导、五个关键画面、数学推导与旋转遮挡。重点防止旧版反面案例那种“图小、右侧只有一句话、完整证明藏在折叠栏”问题。浏览器或本地 file:// 受限要分别注明；不可将未测试写成通过。`scripts/check_html.py` 与 `scripts/browser_smoke.py` 仅作补充，不替代前两项。
10. **交付成品。** 输出可下载的实际文件链接，简述玩法、动画亮点、数学结论、离线状态和实际测试范围。不要只交源码片段。

## 教学内容与镜头顺序（每题从零制作）

- **题目理解**：原题与必要图，条件高亮，符号含义，求解目标；检查遗漏条件。
- **基础知识**：不跳概念，动态给出几何/函数直观，说明定理成立条件和错因。
- **解题思路**：从题意发现突破口，为什么此方法比盲算有利。
- **完整解答**：关键公式按依据逐步出现，并与运动的数学对象一一对应；证明必须严谨完整。
- **总结与巩固**：答案、方法路线、易错点、至少一个带反馈的小问题。

## 按题型强制实现

- **函数/导数**：先坐标轴后**真正逐点生长的曲线**；运动点及坐标；关键点短暂停顿/突出；若涉及导数，切线随点移动并显示斜率/符号和升降；若涉及参数，实时更新曲线、根、极值并限制参数；比较题画原函数/辅助函数或相应差值。旧参考 `examples/旧版教学视觉参考（非V2技术模板）/函数生长_切线_完整离线示例.html`；新工程必须以 V2 标准时间线技术示例为骨架。
- **空间几何**：有真实三维投影与可拖动视角/缩放，翻折按保距刚体变换；显式画轴、透明面、辅助面、法向量、角/二面角；同一空间模型贯穿证明。教学内容参考 `examples/旧版教学视觉参考（非V2技术模板）/2025新高考II卷_第17题_完整成品.html`；它不是 V2 工程验收样例。
- **其他题型**：按数学对象选择数列逐项生成、圆与函数联动、概率实验、解析几何轨迹等；不是每题都套 3D 或同一个模板。

## V3 页面教学硬性要求（若违反，即使 V2 工程测试通过也不合格）

- **首屏按第17题认可成品的交互逻辑组织**：醒目的数学主舞台 + 可点击章节导航 + 当前完整教学微步骤卡片 + 播放器/进度 + 关键思考互动。禁止把视频舞台和一块小文字提示拼在一起就叫微课堂。
- **知识点不只是名词/公式**：按“为什么需要→独立动态图示→概念/条件→定理→本题迁移→理解检验”的顺序呈现；从基础教学，不能假定学生天然懂定理。
- **完整推导随动画推进**：当前学习步骤要在右侧看到目标、原因、推导、结论与提示，不用展开页底 `<details>` 才能找到完整证明。
- **实际参考成品先于技术演示**：第17题“首选视觉交互参考”是界面/体验的事实标准；技术模板只是底层时间轴架构，**禁止照技术演示的简单外观制作最终高考课件**。
- **新题 V3 UI 语义标记必须有**：`data-lesson-region=stage|teaching-side|chapter-nav|teaching-card|controls`、`data-lesson-role=step-title|objective|why|derivation|conclusion|reflection`，控制数据都来自同一个时间轴。
- **交付前必须做视觉教学行为测试和真人/视觉模型审片**，脚本与截图一致仍须检查数学意义和教学有效性。

## 硬性验收门槛

如果只有图形、只有答案、只有章节轮播、不能离线、数学未验证、关键推导不完整、动画与公式脱节、实际没有测试，**都不得自称「完整教学版」**。出现浏览器或能力限制时，说明限制并交付目前完成的可验证内容，不能编造成功。

## V3 新增拒收红线

右侧教学卡只有 `caption+formula`，证明要展开下方折叠区才能看、知识点无独立动态示例、缺少可点击章节导航、场景主体明显过小或标签遮挡、思考题与当前步骤脱节：任一出现都视为教学演示失败。**不要只调颜色或更换标题，必须重写页面教学结构与时间线。**

新版本验证报告见 `references/V3_参考与验收事实.md`。**禁止通过只加入 QA 标记来应付验收：结构约定是测试入口，数学视觉质量仍需要人工审片和内容核对。**
